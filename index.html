Self-contained · one file

Plain HTML, DaisyUI look.

Pico-Daisy vendors PicoCSS itself, so a single stylesheet gives semantic HTML a violet, DaisyUI-inspired theme — dark mode and 7 color variants included. A small set of opt-in classes covers what plain HTML can't express: badges, alerts, avatars, and a few more.
